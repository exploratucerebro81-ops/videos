# FinanzAcademy · Vídeos para redes (Google Vids)

Objetivo: crear vídeos cortos (Reels, TikTok, YouTube Shorts) con Google Vids que lleven tráfico a la web de FinanzAcademy.

## Estructura
- `guiones/` → guiones listos para grabar/montar, uno por vídeo.
- `ideas/banco-de-ideas.md` → próximos vídeos priorizados.
- `BITACORA.md` → memoria del proyecto (pasos dados y decisiones). Pensada para indexarla con graphify.

## Fórmula que usan todos los guiones
1. **Gancho (0-3 s):** frase que para el scroll.
2. **Problema (3-10 s):** el dolor del espectador, en sus palabras.
3. **Solución (10-40 s):** 1 idea práctica, nada de teoría.
4. **Prueba/ejemplo (40-50 s):** números concretos.
5. **CTA (50-60 s):** recurso gratuito en la web (enlace en perfil).

Formato: vertical 9:16, 30-60 s, subtítulos siempre activados (la mayoría ve sin sonido).
